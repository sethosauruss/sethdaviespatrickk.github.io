Project — Home Lab In progress · rebuild starts December

Cybersecurity Home Lab: Infrastructure & Defensive Security

A self-built home lab simulating a small-scale enterprise IT environment, focused on infrastructure security, systems administration, and defensive cybersecurity.

GitHub repository →
U1

Current build

Running on a repurposed Microsoft Surface Pro (broken screen, given a second life as a headless host) with Proxmox VE and Debian Linux. Covers SSH hardening, Fail2Ban intrusion prevention, Docker containerisation, firewall configuration, and authentication log analysis.

Alongside it, a Raspberry Pi 5 runs a small set of self-hosted services under CasaOS — media, monitoring, and a few utilities.

U2

What's being rebuilt — December

Moving from a single-device setup into a proper 6U rack:

A managed switch and a dedicated firewall (pending a teardown of a repurposed Fujitsu thin client to confirm it'll work — cheap secondhand hardware otherwise), a Dell Micro host running the Proxmox lab environment, and a second Raspberry Pi 5 to restore a proper two-node K3s cluster. VLANs will separate Lab, Trusted, and IoT traffic once the firewall and switch are physically installed.

On the lab host itself: Kali Linux, Metasploitable2/DVWA for practice targets, CALDERA and Atomic Red Team for adversary emulation, MITRE ATT&CK Navigator, and a SIEM — still deciding between Wazuh and a self-built ELK stack, mainly weighing resource overlap on a 16GB host running everything else simultaneously.

U3

Documentation

The build is fully documented on GitHub with architecture diagrams and config files. Video walkthroughs of the physical build — hardware teardown, rack assembly, cabling — will be added here once the December rebuild is done.
